# О Полке

Это публичный справочный сайт Полки для пользователей. Читать страницы можно без входа в аккаунт.

На сайте собраны три раздела:

- **О Полке** — информация о продукте и ответы на вопросы.
- **Документы** — опубликованные условия и правила использования.
- **Релизы** — новости об основных обновлениях продукта.

Описание возможностей Полки будет добавлено по мере подготовки материалов.
